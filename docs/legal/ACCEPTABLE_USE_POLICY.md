# Acceptable Use Policy (Draft)

You may not use Inkwell to:

- Store, generate, or distribute content that's illegal in your jurisdiction.
- Attempt to access another user's account, project, or data (including by probing for security
  vulnerabilities without authorization — if you find one, please report it responsibly to
  [security contact — TBD] instead).
- Abuse the AI Assistant to generate content unrelated to your creative writing in a way that circumvents
  usage limits, or to attempt to extract another user's data through it (structurally prevented at the
  database level regardless — see `docs/SECURITY.md` — but still against these terms).
- Use automated tools to scrape, bulk-export, or overload the service beyond normal individual use.
- Impersonate another person or misrepresent your affiliation with any person or entity.
- Upload malicious files (this applies mainly to future file-upload features like DOCX import or media
  uploads — current import only accepts plain text/Markdown, parsed as text, never executed).
